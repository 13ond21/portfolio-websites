Countdown Crew

Shared countdown timers for group events

Android app · Free + Premium (£2.99/mo)

What is Countdown Crew?

Countdown Crew lets you create a shared countdown to any event — birthdays, trips, exams, releases, weddings — and sync it live with the whole group. Friends join via one link, everyone sees the same ticking timer, and milestone notifications fire for the whole crew.

Features

⏰

Shared live timers

Create a countdown, share a link, and every crew member sees the same live countdown.

🔗

One-tap join

Friends tap your link and join instantly — no account or signup needed.

🔔

Milestone notifications

Automatic alerts at 1-week, 1-day, and day-of milestones for all members.

💬

Comment thread

Premium members can hype each other up in the countdown's comment thread.

Free vs Premium

Free: unlimited countdowns, default milestone notifications, up to 10 members.

Premium (£2.99/mo or £1.99 one-off unlock): unlimited members, comment threads, custom milestone times, home-screen widget.

No ads on the countdown screen — this is a low-friction utility.
