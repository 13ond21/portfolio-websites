This page is the complete list of what is inside the app: all 36 sounds with the identifier the app stores them under, the open-source libraries it is built on, and the licences that apply. It is generated from the app's own catalogue (SoundCatalog.kt), which the release build refuses to ship if it disagrees with the audio files in res/raw — so a sound cannot appear in the app without appearing here.

Where the sounds come from

Every sound in this release is CloudyNI in-house sound design: synthesised and mixed for this app under the licence Synthesised for CloudyNI — royalty-free, exclusive. Nothing is sampled from a commercial library, no third-party recording is redistributed, and no attribution obligation is carried by any individual clip.

The audio is generated reproducibly by scripts/generate-placeholder-sounds.ps1, and scripts/verify-audio-assets.ps1 checks every file. The identifiers below are permanent: replacing a placeholder recording with a real one later changes the file and its licence line, never the identifier — so favourites and the Haunted Doorway rotation survive an audio update.

If a future release does bundle a CC0 recording from Freesound, the Sonniss GDC bundle or Mixkit, the clip's own source and licence will be written into the catalogue and will appear in the table below before that build ships.

Fonts

No fonts are bundled with the app. It uses the device's own system font with the Material 3 type scale, so the text matches the rest of your phone and the download stays small. This website, by contrast, uses Outfit and JetBrains Mono under the SIL Open Font License via Google Fonts, with a system-font fallback if that request fails.

Something looks wrong?

If a sound is credited incorrectly, or you believe one of your recordings has been used without permission, email support@cloudyni.com with the identifier from the table and we will investigate, remove the clip and republish. We would much rather fix a credit than argue about one.
